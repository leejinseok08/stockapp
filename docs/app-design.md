# 앱 구성 설계 (2026-09-25 확정 · 같은 날 구현·배포)

## 앱의 역할

1. **개별종목 매매 판단 (중심 기능):** 종목마다 매일 BUY / SELL / 보유 / 관망 신호를 보여준다. 신호 옆에는 종목 리포트(의견·목표가·논거·촉매·리스크)를 둔다.
2. **시장 맥락:** 지금 시장이 얼마나 위험한지 보여준다(위험 경고, 시장 온도, 지수, 수급, 환율). 매매를 지시하지 않는다.
3. **계좌:** 보유 종목 손익과 ISA 한도·만기를 보여준다.

**ISA ETF(S&P500·나스닥100·미국반도체):** 정액으로 적립하고, 앱은 매수 시점이나 금액을 안내하지 않는다. 근거는 `docs/signal-research.md`에 있다.

## 탭과 화면

```
[오늘]  [종목]  [시장]  [계좌]
```

### 1. 오늘 (첫 화면)
매일 한 번 열어서 30초 안에 볼 것만 둔다.

- **분할매수 (살 날에만):** ISA ETF 3개 중 오늘(또는 다음 거래일) 살 차례인 것, 이번 달 몫 금액(계좌 > ISA 설정의 월 적립금 × 40/30/30), 사는 이유(전일 하락이 평소의 몇 배인지 또는 월말), 방법 3줄, 이번 달 나머지 진행, 규칙과 과거 성적(−0.2%). 살 날이 아니면 카드 자체가 없다. 같은 날 알림 1회(전날 장 마감 후).
- **신호 변경:** 오늘 BUY나 SELL로 바뀐 종목을 보여준다. 없으면 "변경 없음"과 최근 5거래일 안의 변경을 보여준다.
- **위험 경고 요약:** "1/5 · 평상"처럼 한 줄로 보여준다. 누르면 시장 탭으로 간다.
- **다가오는 실적 발표:** 종목 목록 중 14일 안에 발표하는 종목을 날짜순으로 보여준다(리포트의 촉매).
- **배당 일정:** 목록 종목·ETF 중 30일 안 배당락일. 회사가 발표 전이면 지난 지급 간격으로 계산하고 "예상"을 붙인다.
- **보유 손익:** 통화별로 한 줄씩 보여준다. KRW와 USD는 합치지 않는다.

### 2. 종목
- **대상:** 빅테크 9개(매그니피센트7, 삼성전자, SK하이닉스)는 기본으로 들어 있다. 관심종목에 추가한 종목도 같은 목록에 들어간다.
- **목록 한 줄:**
  - 심볼과 이름
  - 신호 배지 (BUY / SELL / 보유 / 관망)
  - 의견과 기본 시나리오 상승 여력
  - 재무 점수
- **정렬:** 신호, 의견, 상승 여력, 재무 점수. 기존 "종목 비교" 화면을 대체한다.
- **헤더:** 종목 추가(+) 버튼. 추가 화면 검색창은 국내·미국 전 종목(네이버 자동완성)을 찾는다.
- **재무 점수 기준:** 빅테크 9개 그룹 안의 백분위다. 그룹 밖 종목은 점수 없이 변화율만 보여준다.

### 2-1. 종목 리포트 (목록에서 종목을 누르면 열림)
위에서 아래로 증권사 리포트 첫 페이지 → 근거 순서로 배치한다.

1. **첫 페이지**
   - 의견(매수/중립/매도)과 확신도, 현재가
   - 기본 목표가와 상승 여력, 약세·기본·강세 시나리오 막대
   - **오늘의 신호와 이 규칙의 과거 성적:** 보유 대비 최종 평가액, 원금 대비 최악 손실 비교, 매매 횟수. 성적은 신호 옆에 항상 붙여서 보여준다.
   - 핵심 논거 2~3개, 촉매(다음 실적 발표), 리스크
   - 시장 컨센서스(증권사 목표가) vs 자체 추정. 둘은 섞지 않는다.
2. **가격 차트:** 200일선을 그리고, 과거 BUY/SELL 지점을 표시한다. 누르고 있거나(웹은 마우스를 올리면) 그날 날짜·종가·평균선 값을 보여준다.
3. **지수 대비 상대강도:** 미국 종목은 S&P500, 한국 종목은 코스피 대비로 본다.
4. **재무 변화율:** 분기 성장률과 재무 점수.
5. **펀더멘털 스노우플레이크:** 공시만 쓴다(한국 DART 사업보고서 연결, 미국 SEC 10-K XBRL). 5개 축(가치·최근 성장·과거 실적·재무 건전성·배당) × 6개 통과/미달 체크, 축별 0~6점. 축을 누르면 체크마다 실제 수치가 나온다. 아래에 주요 지표(최근 공시 + 현재가)와 최대 6년 연간 공시 표, 출처 링크. 가격만 시세를 쓴다. Simply Wall St의 "Future" 축은 예측이 필요해서 최근 공시 기준 "최근 성장"으로 바꿨다.
   - **배당·분배금:** 다음 배당락일(예상 표시), 주기, 최근 1회, 최근 1년 합계, 배당수익률.
   - **공시(한국만):** DART 최근 90일 목록, 누르면 원문.
   - 재무제표(분기)
6. **뉴스:** 기존 뉴스 탭에서 옮겨온다.
7. **내 포지션 · 메모**

### 3. 시장
위험 경고(5개 지표) → 시장 온도(참고) → 지수 → 수급 → 환율 순서로 둔다.

### 4. 계좌
- 보유 종목 손익은 통화별로 보여준다. 통화가 둘 이상이면 원화 환산 합계를 위에 두고 쓴 환율(오늘 USD/KRW, 환차손익 제외)을 적는다.
- 매수일을 넣은 종목은 같은 기간 지수(미국 S&P500, 한국 코스피) 수익률과 차이를 보여준다.
- 알림 켜기/끄기(Web Push). BUY/SELL 변경과 위험 경고 "경계"만, 장 마감 후 하루 한 번. iPhone은 홈 화면에 추가한 앱에서만 된다.
- ISA 한도, 의무가입 만료일, 비과세 한도를 진행 막대와 함께 보여준다. 비과세 막대는 국내 상장 보유분 평가이익 기준.
- 보유 수량 입력은 종목 리포트의 "내 포지션"에서 한다.

## 없애는 것
- 뉴스 탭 → 종목 리포트 안으로 옮긴다
- 종목 비교 화면 → 종목 목록의 정렬로 대체한다
- 40/30/30 적립 계획, 매수일 가이드, 매수 배수 권고
- ISA 목표 비중 비교

## 매매 신호 규칙 (추세형)
- **SELL:** 종가가 200일선 아래이고, 200일선이 하락 중이고(20거래일 전보다 낮음), MACD 기울기도 하향이다.
- **BUY:** 현금 상태에서 종가가 200일선 위로 올라오고 MACD 기울기가 상향으로 돌아선다.
- **판단 시점:** 종가로 판단하고, 매매는 다음 거래일에 한다.
- **표시:** 신호와 과거 성적을 함께 보여준다(`app/data/trend_backtest.json`).
  - 2005~2026 기준, 매달 적립하면서 이 규칙을 따르면 최종 평가액이 그냥 보유할 때보다 −30 ~ −73%였다.
  - 반대로 원금 대비 최악 손실은 대부분 줄었다. 하이닉스는 −74%에서 −34%로 줄었다.
  - 이 사실을 숨기지 않는다.

## 목표가 모델 (사이클 보정)
- **기본 틀:** 자체 추정과 증권사 컨센서스를 분리한다. EPS는 컨센서스 추정치를 쓰고, 멀티플은 그 종목의 과거 값을 쓴다.
- **사이클 종목 판정:** 연도별 EPS의 최대/최소가 3배를 넘거나 적자 연도가 있는 종목이다.
- **사이클 종목 처리:**
  - EPS가 과거 중앙값의 절반에 못 미치는 해의 PER은 뺀다. 이익이 바닥인 해는 PER이 부풀기 때문이다.
  - PBR 기준 목표가(주당순자산 × 과거 PBR 범위)를 PER 기준과 평균 낸다.
- **강세 목표가:** 증권사 최고 목표가를 넘지 않게 제한한다. 약세 목표가도 증권사 최저 목표가보다 낮게는 내지 않는다(컨센서스가 있을 때만).
- **투자의견:** 기본 시나리오 상승 여력이 ±15% 밖이면 매수 또는 매도, 안이면 중립이다. 세 시나리오가 모두 같은 방향이면 확신 "높음"이다.

## 표시 규칙 (DESIGN.md를 따름)
- BUY/SELL 배지는 방향을 뜻하는 빨강·파랑을 쓰지 않는다. 텍스트와 테두리만 쓴다.
- 오늘 바뀐 신호는 행동이 필요한 것이므로 강조색(amber)으로 표시한다.
- 의견·목표가 옆에는 항상 기준(현재가, 컨센서스)을 같이 적는다.
- 성적은 그대로 표시한다. 모든 화면에 "투자 권유 아님"을 적는다.

## API

| `/stocks/{symbol}/trend`, `/relative`, `/stocks/scan` | 있음 | 그대로 쓴다 |
| `/market/*` | 있음 | 그대로 쓴다 |
| `GET /stocks/search?q=` | 있음 | 국내·미국 전 종목 검색 |
| `GET /stocks/{symbol}/snowflake` | 있음 | 공시 기반 5축 점수, 지표, 연간 공시 |

## 구현 순서
1. **백엔드:** 목표가 모델 사이클 보정, 차트용 과거 신호 지점, `/today`, `/stocks/list`, 테스트.
2. **앱:** 탭 구조 변경(오늘·종목·시장·계좌), 종목 목록, 종목 리포트 재배치, 뉴스와 비교 화면 제거.
3. **확인:** 웹 렌더링으로 화면 확인 → 커밋·배포 → 배포 서버 데이터 확인(Yahoo가 서버에 주지 않는 값이 있는지).
